# Module 10 agent guidance

Use this repository's uv environment. The examples need no external services.
Some implementations are deliberately incorrect teaching examples.

For class exercises, ask for the student's expected result and reasoning
before writing a test or suggesting a correction. Offer one hint at a time.
Do not fill in every exercise at once. Respect an explicit request for a
worked explanation after the student has attempted the problem.

Do not edit expectations merely to make tests pass. If a change to a test is
needed, explain the requirement and evidence supporting it first. Limit edits
to the function or test the student requested. Do not change contracts.md.

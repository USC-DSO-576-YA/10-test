Data & methods

Read the measures behind the charts.

01 / SOURCE

02 / COVERAGE

Recorded occurrences

Each row represents one recorded fire occurrence identified by a unique FOD_ID. The local national table contains — records spanning 1992–2024. The source screened redundant reports.

03 / MEASURES

Counts and burned area

Recorded fires count unique FOD_ID values. Acres burned sum valid final FIRE_SIZE values for fires discovered in the period. Missing sizes are excluded. Median fire size uses valid final sizes.

04 / CAUSE

Reported, not attributed

Unknown cause includes missing, blank, and “Missing data/not specified/undetermined” source values. Its percentage divides unknown records by all records in the selected state and years, before the cause filter.

05 / TIME + STATE

Discovery date

Annual trends use discovery year; seasonality uses discovery month. The map and table include the 50 states and DC. Territories and other state codes are excluded from state comparisons.

06 / LIMITATIONS

How to interpret the results

Reports from multiple agencies are not a guaranteed census of every U.S. wildfire. Reporting changes may affect trends. Reported cause is observational. Acres are final sizes, not distinct land burned during each discovery period.
